//1. Abstraction (Complexity chhupana) 
Aap phone use karte waqt sirf screen aur buttons se interact karte hain. Aapko ye jaanne ki zaroorat nahi hoti ki andar processor kaise kaam kar raha hai ya circuit kaise juda hai.
Programming mein: Sirf zaroori details dikhana aur baaki ki implementation details chhupa dena.
2. Encapsulation (Data ko safe rakhna)
Phone ki battery, RAM, aur internal wiring ek body ke andar pack (encapsulate) hoti hai. Aap bahar se directly unhe touch nahi kar sakte.
Programming mein: Data (variables) aur functions ko ek single unit (Class) mein band karna aur bahar se direct access rokna taaki koi galti se data change na kar de. 
3. Inheritance (Purani cheez se nayi banana)
Apple ne iPhone 14 banaya, fir iPhone 15 banaya. iPhone 15 ne purane model ke saare features (calling, camera, apps) liye aur apna kuch naya feature add kar diya.
Programming mein: Ek bani-banayi class ki properties aur methods ko doosri class mein use karna taaki baar-baar code na likhna pade.
4. Polymorphism (Ek naam, alag kaam)
Phone ka ek hi "Power Button" alag-alag kaam karta hai:
Single press: Screen ON/OFF
Long press: Switch Off / Restart
Programming mein: Ek hi function ya method ko alag-alag situations mein alag tarike se behave karwana.
